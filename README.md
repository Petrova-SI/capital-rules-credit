# Capital Rules & Credit

A static, six-page English-language student project. The site uses plain HTML, CSS and JavaScript; no build step or external service is required to serve it.

## GitHub Pages

1. Create a public GitHub repository named `capital-rules-credit`.
2. Upload all files and the `assets` folder from this directory to the repository root.
3. In **Settings → Pages**, set the source to deploy from the `main` branch and the `/ (root)` folder.
4. Wait for GitHub Pages to finish publishing. The public link will appear in the same settings panel.

On GitHub Free, Pages requires a public repository, so the source files in that repository will also be visible. The published site itself does not include a ChatGPT or Tilda badge.
